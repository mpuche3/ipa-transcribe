# Transcription review: decisions

The descriptions below record the forms as they were found during review.
Locations identify examples, not necessarily every occurrence of the same
form.

The author selected the option marked with `>` for each question. Those
decisions have been applied and recorded in the guide and correction ledger.
Merriam-Webster remained inaccessible during review; other references are
linked where they help explain an option.

## Pronunciation and stress

1. **phenomenon** — [TRN_Gaslighitng.md](examples/TRN_Gaslighitng.md), line 2,
   uses `fənɒ́mənɒ̀n`, while [TRN_TheMereExposureEffect.md](examples/TRN_TheMereExposureEffect.md),
   line 2, uses `fənɒ́mənən`. Both final vowels occur in American dictionaries;
   the guide selects Merriam-Webster's first listing, which could not be
   verified during this review. Which form should the corpus use?

    > **A.** Use `fənɒ́mənɒ̀n`. This retains the full final vowel and secondary
    > stress shown in an [American pronunciation](https://en.wiktionary.org/wiki/phenomenon).

    **B.** Use `fənɒ́mənən`, with a reduced final syllable.

2. **valuable** — [TRN_TheFlashCrash.md](examples/TRN_TheFlashCrash.md), line 5,
   uses `vǽljuwəbəl`, while [TRN_TheAlignmentProblem.md](examples/TRN_TheAlignmentProblem.md),
   line 15, uses `vǽljəbəl`. Dictionaries list both the full and reduced
   vowels. Which reading should take precedence?

    > **A.** Use `vǽljuwəbəl`, retaining the vowel of *value*. This is the
    > first American form shown by [Dictionary.com](https://www.dictionary.com/browse/valuable).

    **B.** Use the reduced `vǽljəbəl`.

3. **outside** — [TRN_AgentHackingHuggingFace.md](examples/TRN_AgentHackingHuggingFace.md),
   lines 2–3, has `áwtsàjd` for both an adjective and an adverb;
   [TRN_ClimbingWithoutARope.md](examples/TRN_ClimbingWithoutARope.md), line 3,
   has `awtsájd` for an adverb; and
   [TRN_HomeOrAsset.md](examples/TRN_HomeOrAsset.md), line 16, has `àwtsájd`
   for a preposition. Stress can depend on grammatical role and dictionary
   listing. Should these forms be standardized by role?

    > **A.** Use `áwtsàjd` for the adjective and `àwtsájd` for the adverb and
    > preposition, distinguishing their [attested stress patterns](https://en.wiktionary.org/wiki/outside).

    **B.** Use `áwtsàjd` for all three roles.

    **C.** Use `àwtsájd` for all three roles.

4. **strength** — [TRN_TheMereExposureEffect.md](examples/TRN_TheMereExposureEffect.md),
   line 6, has `strɛ́ŋkθ`, while [TRN_Habituation.md](examples/TRN_Habituation.md),
   line 5, has `strɛ́ŋθ`. Dictionaries list both pronunciations; should the
   optional `k` be written?

     **A.** Use `strɛ́ŋkθ`, with `k`. [Dictionary.com](https://www.dictionary.com/browse/strength)
     lists this American variant first.

    > **B.** Use `strɛ́ŋθ`, without `k`.

5. **concrete** — [TRN_Move37.md](examples/TRN_Move37.md), line 10, has
   `kɒ̀nkríjt`; [TRN_SpainHousingCrisis.md](examples/TRN_SpainHousingCrisis.md),
   line 5, has `kɒ́ŋkrijt`; and
   [TRN_TheDiscoveryOfChess.md](examples/TRN_TheDiscoveryOfChess.md), line 28,
   has `kɒ́nkrijt`. Dictionaries vary in stress and `n`/`ŋ`, including by
   grammatical role. Which readings should be used in these contexts?

    The three cited uses are adjectives.

    > **A.** Use `kɒ́nkrijt` for all three: first-syllable stress and `n`
    > rather than writing nasal assimilation. This is an
    > [attested American pronunciation](https://www.dictionary.com/browse/concrete).

    **B.** Use `kɒ́nkrìjt`: first-syllable stress with secondary stress on
    the second syllable.

    **C.** Use `kɒ̀nkríjt`: primary stress on the second syllable.

    **D.** Use `kɒ́ŋkrijt`: first-syllable stress with `ŋ`.

6. **themselves** — [TRN_NicaraguanSignLanguage.md](examples/TRN_NicaraguanSignLanguage.md),
   line 7, and [TRN_TheTuringMachine.md](examples/TRN_TheTuringMachine.md),
   line 7, use `ðɛmsɛ́lvz` in emphatic uses; other examples use
   `ðəmsɛ́lvz`. Should the full vowel be retained, and if so should it have
   secondary stress?

    > **A.** Keep `ðɛmsɛ́lvz` in the cited emphatic uses and `ðəmsɛ́lvz` in
    > neutral uses. Do not add a grave: a full vowel alone does not require
    > secondary stress under §5.2.

    **B.** Use `ðəmsɛ́lvz` in both neutral and emphatic uses.

    **C.** Use `ðɛ̀msɛ́lvz` in emphatic uses and `ðəmsɛ́lvz` in neutral uses.

7. **difficulty** — [TRN_TheEscalationOfCommitment.md](examples/TRN_TheEscalationOfCommitment.md),
   line 9, uses `dɪ́fɪkə̀ltij`, while most examples use `dɪ́fɪkəltij`.
   Dictionaries differ on whether the third syllable carries secondary stress.
   Which form should the corpus use?

    > **A.** Use `dɪ́fɪkə̀ltij`, retaining the secondary stress shown in
    > [Dictionary.com's American pronunciation](https://www.dictionary.com/browse/difficulty).

    **B.** Use `dɪ́fɪkəltij`, without the secondary stress.

8. **whatever** — [TRN_TheY2KNonEvent.md](examples/TRN_TheY2KNonEvent.md),
   line 8, has `wə̀tɛ́vər`, whereas other examples use `wɒtɛ́vər`. American
   dictionaries list different first vowels and stress markings. Which form
   should the corpus use?

    > **A.** Use `wətɛ́vər`, with an unmarked STRUT vowel. This maps an
    > [American pronunciation](https://www.dictionary.com/browse/whatever)
    > into the guide's `ə` notation.

    **B.** Use `wɒtɛ́vər`, with LOT in the first syllable.

    **C.** Use `wə̀tɛ́vər`, retaining secondary stress on the first syllable.

9. **researchers** — [TRN_CognitiveLoad.md](examples/TRN_CognitiveLoad.md),
   line 24, uses `rɪsɜ́rtʃərz`, while
   [TRN_HowBrandsGrow.md](examples/TRN_HowBrandsGrow.md), line 9, uses
   `ríjsɜ̀rtʃərz`. The related word *research* also varies between
   `ríjsɜrtʃ`, `ríjsɜ̀rtʃ`, and `rɪsɜ́rtʃ`, for example in
   [TRN_TheToyotaWay.md](examples/TRN_TheToyotaWay.md), lines 21 and 39.
   Which stress and first vowel should these forms use?

    > **A.** Use `rɪsɜ́rtʃ` for *research* and `rɪsɜ́rtʃərz` for
    > *researchers*. This keeps the family consistent and follows an
    > [American pronunciation](https://www.dictionary.com/browse/research)
    > with stress on *search*.

    **B.** Use `ríjsɜ̀rtʃ` and `ríjsɜ̀rtʃərz`, with first-syllable
    primary stress and a grave on *search*.

    **C.** Use `ríjsɜrtʃ` and `ríjsɜ̀rtʃərz`, omitting the grave in
    the shorter *research* form.

    **D.** Distinguish roles: use `ríjsɜ̀rtʃ` for the noun *research*,
    `rɪsɜ́rtʃ` for the verb, and `rɪsɜ́rtʃərz` for *researchers*.

10. **Australia** — [TRN_HomeOrAsset_Long.md](examples/TRN_HomeOrAsset_Long.md),
    line 50, uses `ɔstréjlijə`, while
    [TRN_HowBrandsGrow.md](examples/TRN_HowBrandsGrow.md), line 7, uses
    `ɔstréjljə`. Should the vowel before the final schwa be kept?

    > **A.** Use `ɔstréjljə`, with a glide before the final schwa. It is an
    > [attested General American form](https://en.wiktionary.org/wiki/Australia).

    **B.** Use `ɔstréjlijə`, retaining the extra vowel.

11. **Song dynasty** — [TRN_AHomeOrAnAsset.md](examples/TRN_AHomeOrAnAsset.md),
    lines 147 and 151, uses English-style `sɒ́ŋ` for the Chinese dynasty.
    Section 14 calls for the original language's pronunciation; is Mandarin
    `sʊ̂ŋ` the intended form here?

     **A.** Use Mandarin `sʊ̂ŋ`, including its falling tone, in accordance
     with §14's treatment of foreign names.

    > **B.** Keep `sɒ́ŋ` as an explicit English-style exception for this name.

12. **beneficiaries** — [TRN_AHomeOrAnAsset.md](examples/TRN_AHomeOrAnAsset.md),
    lines 709, 1019 and 1099, uses `bɛ̀nɪfɪ́ʃɛ̀rijz`,
    `bɛ̀nɪfɪ́ʃijɛ̀rijz` and `bɛ̀nəfɪ́ʃijɛ̀rijz`, respectively.
    Which vowels and syllables should this word use?

    > **A.** Use `bɛ̀nɪfɪ́ʃijɛ̀rijz`. This keeps the expanded American
    > pronunciation and matches the ledger's `ɪ` in *benefit* and *beneficial*.

    **B.** Use `bɛ̀nəfɪ́ʃijɛ̀rijz`, keeping the expanded form but choosing
    `ə` in the second syllable as an exception.

    **C.** Use `bɛ̀nɪfɪ́ʃərijz`, with the shorter ending.

    **D.** Use `bɛ̀nɪfɪ́ʃɛ̀rijz`, the shorter form currently on line 709.

## Grammatical role

13. **what would follow** — [TRN_TheY2KNonEvent.md](examples/TRN_TheY2KNonEvent.md),
   line 2, has bare `wɒt` in “nobody knew what would follow.” It can be read
   as an embedded question (`wɒ́t`) or as a fused relative (`wɒt`). The guide
   defaults genuinely ambiguous constructions to the latter; is that the
   intended reading here?

    > **A.** Keep `wɒt`, treating it as “the thing or things that would follow”
    > and applying the guide's default for an ambiguous construction.

    **B.** Use `wɒ́t`, treating it as the embedded question “what would follow?”

14. **understand what ...** —
    [TRN_TheToyotaWay.md](examples/TRN_TheToyotaWay.md), line 201, and
    [TRN_ReengineeringTheCorporation.md](examples/TRN_ReengineeringTheCorporation.md),
    line 159, use bare `wɒt` in clauses beginning “understand what.” Should
    these be treated as fused relatives, or as embedded questions with `wɒ́t`?

    > **A.** Keep `wɒt` in both cited clauses: each can be read as “the
    > thing(s) that,” so use the guide's ambiguous-construction default.

    **B.** Use `wɒ́t` in both, reading them as embedded questions.

    **C.** Keep `wɒt` in *The Toyota Way* and use `wɒ́t` in
    *Reengineering the Corporation*.

    **D.** Use `wɒ́t` in *The Toyota Way* and keep `wɒt` in
    *Reengineering the Corporation*.

15. **approximate some** — [TRN_AHomeOrAnAsset.md](examples/TRN_AHomeOrAnAsset.md),
    line 87, uses `səm` in “some two hundred thousand,” while line 925 uses
    `sə́m` in “some three hundred billion.” Should approximate *some* be
    treated as a weak determiner or as an accented adverb?

    > **A.** Use `sə́m` in both: *some* means “approximately” here, so treat
    > it as an accented adverb under §5.2.

    **B.** Use `səm` in both, treating it like the weak indefinite determiner.
